# WeekPay

A simple, playful and modern app where kids earn their weekly allowance by doing chores.

## Idea

- Netflix-style profile picker: add and select children in seconds
- Per child: tap + / – to register completed chores
- Manage chores: add, edit and delete, with price, icon (from an icon library) and color
- Payout: see the amount earned, mark it as paid or reset the balance, so the child starts from zero again. The period (week, month, ...) is up to the parent
- Extremely simple UI: playful, but clean and modern

## Stack

- Vue 3 + TypeScript
- Supabase
- Bootstrap 5 + Sass

## Status

Early stage. Built for personal family use first, with possible public launch later.
